# All Systems Operational

A mid-2010s stomp-clap indie singalong about the Microsoft 365 outage of November 12–14, 2026, filmed as a made-up Seattle public-radio live session ("Session 503"). The narrator is the status page; every time the gang vocals swell, the stream goes down. A sequel to LGTM. The agent does the production; the human approves at each milestone gate, picks takes, and supplies what the agent can't reach (Suno, Logic Pro, audits in other labs' chat apps, screen captures).

**Start here:** the brief is the Claude Doc https://claude.ai/artifact/VPEaJhs55vieCdQcS6C79E (overview, look and callbacks, style prompt and lyrics v1.2, shot list O01–O24, report branches A–C, rendering plan, `incident.json`, bookends, audit plan, guardrails). Read it with the docs tools, not a web fetch; `docs/brief.md` is a plain-text mirror (`scripts/mirror_brief.py`). The planning chat is captured in `docs/planning_chat/`, the Suno take in `docs/suno/`. The milestone plan is `docs/plan.md`. Then read the latest entries of `log/production_log.md` and `log/human_interventions.md`.

- **Conflict of interest:** Claude drafted the lyrics, and Anthropic's Microsoft 365 connector broke in this outage. The creator worked on Outlook and Word at Microsoft about 10 years ago. Any audit finding Claude rejects goes to the human. Nothing on screen ties AI-written code to this outage unless the full post-incident report does.
- **Guardrails (brief):** no real faces, people or invented quotes; no real logos, colours or status-page layouts except the creator's real screenshots in the opening bookend, captioned as real; evoke the Seattle live-session format, never KEXP's identifiers; no water, boats or detailed Space Needle; the New Orleans riverboat crash stays out.
- **Ever Present material:** the figure library, its MPFB assets and the vendored Ever Present scripts (`assets/figures/`, `assets/mpfb/`, `blender/ep/`) come from a private, all-rights-reserved repository. Don't push them or anything derived from them to a public remote without the human's say-so.
- **Logs:** `log/production_log.md` gets one entry per generation, render or analysis step, with the command and output paths. Every human action goes in `log/human_interventions.md`. Anything the generator changed goes in `log/ai_changes.md`; deviations from the brief go in `log/decisions.md`. Every prompt and seed verbatim in `log/prompts/`; auditor outputs verbatim in `log/audits/`. Nothing is deleted: rejects go to `archive/`. One git commit per logged step.
- **Seeds:** every random process reads its seed from `config/seeds.json`; main video seed 41.
- **Large files** (audio, screenshots, figure library, generated assets, renders, the edit) stay out of git; run `scripts/manifest.sh` after adding any. Log the command that regenerates them. The disk is nearly full (34 GB free on 2026-11-15): check `df -h ~` before big renders.
- **Sibling projects** in `~/Projects` are reference only: read them for method, never modify them. `../ever-present` has the latest shared scripts (Blender figure kit, Remotion, timing, cuts); `../sandbox-rhapsody` the probe kit; `../distillation-allegedly/src/defaultOn` the Little Switch rig (upstream: Default On, on the machine `kepler`).
- **Tools:** Python steps run on this repo's `.venv` (`uv sync`; Ever Present's pins: torch 2.8 cu128, WhisperX 3.8.6; WhisperX needs `NLTK_DATA=$PWD/.venv/nltk_data`, kept `go-w`). Captures use Puppeteer (`npm install`; Chrome from `~/.cache/puppeteer`). Blender and image-to-video need the RTX 5090: schedule around other projects' renders and music-deslop training runs. ComfyUI in `~/ComfyUI`. The post-filter is music-deslop in `~/Code/music-deslop`.
